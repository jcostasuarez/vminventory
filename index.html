Configuración del Consultor

Elegí la carpeta de inventario donde están los reportes JSON.

Se conserva para compatibilidad. El Consultor muestra todas las coincidencias que cumplen los filtros.
Cada subcarpeta directa legible define un tipo. El Consultor busca archivos .json dentro de esas carpetas; los archivos en la raíz no se indexan.
Configuración avanzada del Analizador

Ajustes del motor vmspect para rendimiento, acceso a discos, clasificación y bitácora.

Rendimiento
Cantidad de máquinas virtuales que se procesan al mismo tiempo. Más workers pueden acelerar el relevamiento, pero usan más CPU y disco.
Tamaño de los bloques de lectura del disco. Dejálo vacío para que vmspect use el valor recomendado.
Acceso a discos
qemu-nbd es una herramienta externa para montar discos virtuales. Actívala solo si el modo de acceso nativo falla.
La resolución y ejecución del binario pertenecen exclusivamente a vmspect durante la inspección.
Clasificación y reglas
Si está desactivado, se descarta el software que las reglas de clasificación no consideren relevante.
La colmena SYSTEM es una rama del registro de Windows con datos de configuración del equipo. Incluirla amplía el análisis, pero es más lento.
Archivo JSON o TOML con reglas propias de clasificación. Si se deja vacío, se usan las reglas predeterminadas.
Marca las VMs cuyo nombre de carpeta no coincide con el nombre configurado dentro de la máquina virtual.
Seguimiento y bitácora
Muestra un registro técnico detallado durante el relevamiento; útil para diagnosticar errores.
Agrega una barra de progreso adicional para la VM que se está procesando en este momento.

El nombre del archivo de salida se define en el paso “Nombre JSON” del panel principal del Analizador.
